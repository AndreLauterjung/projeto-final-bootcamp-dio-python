# Detector de Transações Inconsistentes com Pandas

> Projeto prático desenvolvido para automatizar a detecção de erros, valores negativos e anomalias em bases de dados transacionais utilizando Python e a biblioteca Pandas.

## Tecnologias Utilizadas
- Python 3.x
- Pandas

## Funcionalidades do Script
1. Carregamento de base de dados simulada.
2. Filtragem automática de valores inválidos (negativos ou zerados).
3. Identificação de registros duplicados por cliente/valor.
4. Alerta de transações com valores atípicos (acima da média esperada).
